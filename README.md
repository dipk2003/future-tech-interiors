# Future Tech Interiors

Cinematic interior design website for Future Tech Interiors, Noida.

Run `npm start`, then open http://127.0.0.1:4173.

The deployable website lives in `dist/`. Three.js is bundled locally in `dist/vendor/`; no build step is required. Google Fonts supplies DM Sans and Cormorant Garamond, with system fallbacks. Interior photographs are illustrative Unsplash images, clearly labelled as concepts rather than client projects.

Features: scroll reveals, responsive navigation, filtered design gallery, native project dialogs, an animated interior installation, direct call links and a consultation form that opens a prefilled WhatsApp message. Nothing is submitted automatically or stored on a server.

The cinematic scene shows an empty room being finished: oak floorboards slide into place, wall panels rise, a rug unrolls, furniture and artwork are installed, and the lights come on. The finite sequence plays when visible, pauses offscreen or in a hidden tab, and presents the finished room for visitors who prefer reduced motion. There are no scene counters, tour controls, scroll instructions, coordinates or demonstration labels. A photograph remains as the fallback when WebGL is unavailable. GSAP and ScrollTrigger supply the opening and page parallax; all libraries are bundled locally.
