# Future Tech Interiors

Cinematic interior design website for Future Tech Interiors, Noida.

Run `npm start`, then open http://127.0.0.1:4173.

The deployable website lives in `dist/`. Three.js is bundled locally in `dist/vendor/`; no build step is required. Google Fonts supplies DM Sans and Cormorant Garamond, with system fallbacks. Interior photographs are illustrative Unsplash images, clearly labelled as concepts rather than client projects.

Features: image transitions, scroll reveals, responsive navigation, filtered design gallery, native project dialogs, interactive WebGL room, three material palettes, daylight/evening lighting, keyboard rotation controls, direct call links and a consultation form that opens a prefilled WhatsApp message. Nothing is submitted automatically or stored on a server.

The cinematic edition adds a sequenced opening curtain, masked headline entrances, slow camera movement, pointer depth, scroll parallax, an architectural sketch-to-interior story with three navigable chapters, reading progress, and a play/pause 3D camera tour. GSAP and ScrollTrigger are bundled locally. Motion respects the visitor's reduced-motion setting; slideshow and room tour have independent playback controls. The design story can be skipped and native scrolling is preserved.
